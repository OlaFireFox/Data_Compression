# 🔄 動畫流程圖解

## 📊 整體流程架構

```
┌──────────────────────────────────────────────────────────┐
│                    播放動畫啟動                            │
└──────────┬───────────────────────────────────────────────┘
           │
           ├─ 初始化狀態
           │  ├─ appState.lastCharPath = null
           │  ├─ appState.animationPlaying = true
           │  └─ progress bars 重置
           │
           ▼
┌──────────────────────────────────────────────────────────┐
│              FOR EACH CHARACTER IN TEXT                   │
│                                                            │
│  charIdx = 0, 1, 2, ...                                   │
└──────────┬───────────────────────────────────────────────┘
           │
           ▼
┌──────────────────────────────────────────────────────────┐
│         1️⃣ 查詢當前字符的編碼路徑                         │
│                                                            │
│  currentPath = findPathToCharacter(char)                  │
│  例: 'a' → [1, 2, 5]                                     │
└──────────┬───────────────────────────────────────────────┘
           │
           ▼
┌──────────────────────────────────────────────────────────┐
│         2️⃣ 路徑對比：currentPath vs lastPath             │
│                                                            │
│  pathsEqual = arePathsEqual(                              │
│      currentPath,      // [1, 2, 5]                      │
│      appState.lastPath // null 或 [1, 2, 5]             │
│  )                                                        │
└──────────┬───────────────────────────────────────────────┘
           │
        ┌──┴──┐
        │ 路徑是否相同？                                      
        │                                                    
   否 (❌)                  是 (✅)                          
   [路徑改變]             [路徑相同]                         
        │                   │                               
        ▼                   ▼                               
┌──────────────────┐  ┌──────────────────┐                
│   3️⃣ 遞進式      │  │   3️⃣ 脈衝       │                
│    高亮動畫      │  │    閃爍動畫      │                
│                  │  │                  │                
│ 🔄 Progressive   │  │ 💫 Pulse Flash   │                
│ Highlight        │  │                  │                
└────────┬─────────┘  └────────┬─────────┘                
         │                      │                         
         │ 執行 0.3s            │ 執行 0.3s               
         │                      │                         
         ▼                      ▼                         
    清除舊高亮         快速脈衝 3 次                      
      │                    │                             
    ├─ drawTree(null)    ├─ 亮起 (50ms)                
    │  50ms 延遲         ├─ 熄滅 (50ms)                
    │                    ├─ 亮起 (50ms)                
    ├─ 逐步亮起           ├─ 熄滅 (50ms)                
    │  步驟 1: [1]       ├─ 亮起 (50ms)                
    │  步驟 2: [1→2]     └─ 熄滅 (50ms)                
    │  步驟 3: [1→2→5]                                  
    │                                                   
    └─ drawTree(path)                                  
       保持完整路徑
       
         │                      │                         
         └────────┬─────────────┘                        
                  │                                      
                  ▼                                      
┌──────────────────────────────────────────────────────────┐
│    4️⃣ 更新路徑狀態                                       │
│                                                            │
│  appState.lastCharPath = currentPath                      │
│  現在: [1, 2, 5] → 下次: lastPath = [1, 2, 5]            │
└──────────┬───────────────────────────────────────────────┘
           │
           ▼
┌──────────────────────────────────────────────────────────┐
│    5️⃣ 播放進度條動畫                                      │
│                                                            │
│  playTransmissionCharacterForStep(charIdx, speed)         │
│  ├─ 計算編碼長度 (bits)                                  │
│  ├─ 原始進度條：固定 0.8s                               │
│  └─ Huffman 進度條：bits × 0.1s                         │
└──────────┬───────────────────────────────────────────────┘
           │
    ┌──────┴────────┐
    │ 所有字符      │
    │ 都處理完了？  │
    │               │
    否 (❌)        是 (✅)
    │              │
    ▼              ▼
  迴圈繼續   ┌─────────────┐
  charIdx++  │ 動畫播放    │
             │ 完成！      │
             │ ✅ END     │
             └─────────────┘
```

## ⏱️ 速度適應示例

### 遞進式高亮時間計算

```
基礎時間：stepDuration = Math.max(100 / speed, 50)

速度 0.5x (慢放)：
├─ stepDuration = 100 / 0.5 = 200ms
├─ 步驟 1：[1]           → 200ms
├─ 步驟 2：[1→2]         → 200ms
└─ 步驟 3：[1→2→5]       → 200ms
   🔄 總耗時：600ms (原速的 2 倍)

速度 1.0x (正常)：
├─ stepDuration = 100 / 1.0 = 100ms
├─ 步驟 1：[1]           → 100ms
├─ 步驟 2：[1→2]         → 100ms
└─ 步驟 3：[1→2→5]       → 100ms
   🔄 總耗時：300ms (基準)

速度 2.0x (快放)：
├─ stepDuration = Math.max(100 / 2.0, 50) = 50ms
├─ 步驟 1：[1]           → 50ms
├─ 步驟 2：[1→2]         → 50ms
└─ 步驟 3：[1→2→5]       → 50ms
   🔄 總耗時：150ms (原速的 0.5 倍)
```

### 脈衝閃爍時間計算

```
基礎時間：pulseDuration = Math.max(300 / speed, 150)
         pulseInterval = pulseDuration / (pulseCount × 2)

速度 0.5x (慢放)：
├─ pulseDuration = 300 / 0.5 = 600ms
├─ pulseInterval = 600 / 6 = 100ms
│  ├─ 脈衝 1: 亮(100) + 暗(100)
│  ├─ 脈衝 2: 亮(100) + 暗(100)
│  └─ 脈衝 3: 亮(100) + 暗(100)
└─ 💫 總耗時：600ms

速度 1.0x (正常)：
├─ pulseDuration = 300 / 1.0 = 300ms
├─ pulseInterval = 300 / 6 = 50ms
│  ├─ 脈衝 1: 亮(50) + 暗(50)
│  ├─ 脈衝 2: 亮(50) + 暗(50)
│  └─ 脈衝 3: 亮(50) + 暗(50)
└─ 💫 總耗時：300ms

速度 2.0x (快放)：
├─ pulseDuration = Math.max(300 / 2.0, 150) = 150ms
├─ pulseInterval = 150 / 6 = 25ms
│  ├─ 脈衝 1: 亮(25) + 暗(25)
│  ├─ 脈衝 2: 亮(25) + 暗(25)
│  └─ 脈衝 3: 亮(25) + 暗(25)
└─ 💫 總耗時：150ms
```

## 🎯 條件判斷流程

```
          是否相同？
            /\
           /  \
         /      \
     NO /        \ YES
       /          \
      ▼            ▼
  遞進式高亮    脈衝閃爍
  (Progressive) (Pulse)
  
  步驟 1: 清除   亮 (50ms)
  步驟 2: 亮起   暗 (50ms)
  步驟 3: 保持   亮 (50ms)
          暗 (50ms)
          亮 (50ms)
          暗 (50ms)
          完成高亮
```
